# 管理员登录与公开分享

NASFlow 使用一个管理员账号保护主页、媒体库、Cookies、订阅、设置和直接文件下载。
后端统一校验登录会话；直接访问 API 端口也不会绕过保护。未登录的管理 API 返回 401，
主页和 `/media/play/{id}` 跳转到 `/login`。

## 首次登录

服务第一次启动时自动生成管理员账号 `admin` 和随机密码，写入 NAS 数据目录中的
`admin-initial-password.txt`。Docker 默认位置是容器的 `/data/admin-initial-password.txt`，
对应 compose 文件旁的 `data/admin-initial-password.txt`。文件只对其所有者开放读写，
不会经网页或 API 返回。请在 NAS 文件管理器中读取自己的首次登录信息。

也可在**首次启动之前**设置 `NASFLOW_ADMIN_USERNAME` 和 `NASFLOW_ADMIN_PASSWORD`。
已存在账号时不会因重启或环境变量变动而重置密码。不要把带密码的 compose 配置提交到 GitHub。

登录后进入“系统设置 → 登录安全”可修改账号和密码，必须提供当前密码。
修改成功后撤销所有设备的管理员会话，并删除初始密码文件；所有设备需要重新登录。

## 会话

- 密码采用随机盐和 PBKDF2-HMAC-SHA256（600,000 轮）存储，不保留用户设置的明文密码。
- 登录令牌使用随机 256 位值，数据库仅保存其 SHA-256 摘要。会话有效期 7 天；退出登录立即撤销当前会话。
- Cookie 设置 HttpOnly、SameSite=Lax；HTTPS 访问设置 Secure。浏览器提交的变更请求会校验 Origin，
  代理覆盖转发的主机名，并识别 Cloudflare TLS 终止后的 HTTPS 协议。
- 登录和修改密码限制同一来源 5 分钟内最多 10 次尝试。下载线程和订阅定时器无需网页会话。

## 分享隔离

公开入口包括：健康检查、登录 POST、随机令牌的分享元信息 GET、分享开始播放 POST，
以及分享视频流 GET/HEAD。分享链接撤销 DELETE 和分享列表需要管理员登录。

管理员调用手机外部播放器时，后端另外签发仅限该视频、8 小时有效的随机授权链接，
让不能携带网页登录 Cookie 的播放器继续工作。签发接口必须登录；退出登录或修改密码后
该授权立即失效。分享页面不提供此功能。

分享页 Logo 是普通文字，且无主页入口、下载按钮或外部播放器入口。
修改地址进入主页或直接请求普通视频下载/视频流都会触发管理员验证。
分享接口沿用次数限制、累计流量限制、播放会话 Cookie 和下载目录校验。

Cloudflare Access 如保护整个域名，接收者仍需要通过其邮箱认证。
如果希望分享免 Cloudflare 登录，单独为 `/media/share/*` 和 `/nas-api/api/shares/*`
配置公开路径；管理操作仍受 NASFlow 自己的登录验证保护。播放器样式、脚本和图标等静态资源也须可访问。

## 验证

运行 `python -m unittest discover -s tests -p 'test_*.py' -v`。
无痕窗口打开主页应出现登录页；直接调用任务、Cookies、设置和普通下载 API 应返回 401。
登录后下载和媒体库可正常使用。无痕窗口打开分享链接能读取对应视频；修改密码后旧会话和旧密码失效。
